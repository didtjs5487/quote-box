문장 갈피

사용설명서

마음에 남는 문장을 태그로 모아두고, 언제든 꺼내 보고, 붓글씨 카드 이미지로 만들어 나눌 수 있는 앱이에요. 로그인도 회원가입도 없어요.

시작하기문장 담기오늘의 한마디찾기·정리 카드 버튼카드 이미지백업그 밖의 기능자주 묻는 질문

1시작하기

주소를 열면 바로 쓸 수 있어요. 설치는 선택이지만, 앱처럼 쓰려면 홈 화면에 추가해 두면 편해요.

  • 안드로이드(크롬): 주소창 오른쪽 ⋮ → 홈 화면에 추가 또는 앱 설치
  • 아이폰(사파리): 아래 공유 버튼 → 홈 화면에 추가
  • PC: 크롬 주소창 오른쪽의 설치 아이콘
계절에 맞춰 배경이 바뀌어요. 봄 3~5월 · 여름 6~8월 · 가을 9~11월 · 겨울 12~2월이에요.

2문장 담기

  1. 오른쪽 아래의 ＋ 버튼을 누르면 새 문장 담기 칸으로 이동해요.
  2. 문장만 적어도 저장돼요. 출처(영화, 책, 사람 이름), 링크(영상·기사 주소), 느낀 점, 태그는 선택이에요.
  3. 담아두기를 누르면 목록 맨 위에 카드가 생겨요.

태그는 쉼표로 구분해 마음대로 붙여요. 예: 명언, 위로, 말씀. 태그가 쌓이면 위쪽에 필터 버튼으로 나타나요.

3오늘의 한마디

맨 위의 검은 카드는 모아둔 문장 중 하나를 골라 보여줘요. 글자가 먹물처럼 번지며 나타나요.

  • 🎲 다른 문장으로 바꿔요.
  • − / + 글씨 크기를 4단계로 조절해요. 고른 크기는 기억돼요.

4찾기·정리

  • 검색창에 문장, 출처, 태그, 느낀 점의 일부를 적으면 찾아줘요.
  • ↕️ 최신순 · 오래된순 · 랜덤 순서를 바꿔요.
  • 전체 / ⭐ 즐겨찾기 / 🔥 자주 보는 필터로 모아봐요. 오늘의 한마디로 자주 뽑힌 문장이 자주 보는이에요.
  • #태그 버튼이나 카드의 태그를 누르면 같은 주제끼리 모아봐요.
  • 오른쪽 위 📊에서 지금까지 모은 문장 수, 월별 기록 등을 볼 수 있어요.

5카드 버튼과 느낀 점 기록

카드 아래쪽 세 개의 아이콘이에요.

이미지로 공유 — 붓글씨 카드 이미지를 만들어요. 수정 — 문장·출처·링크·태그를 고치거나 삭제해요. 잘못 열렸다면 취소를 누르세요. 즐겨찾기 — 누르면 카드 오른쪽 위에 붉은 낙관이 찍혀요.

느낀 점 남기기: 카드의 문장 글씨를 누르면 그 자리에서 느낀 점을 적을 수 있어요. 댓글처럼 여러 개를 이어서 남길 수 있고, 날짜가 함께 기록돼요. 기록을 누르면 고치고, ✕를 누르면 지워요.

6카드 이미지 만들기

카드의 이미지 아이콘을 누르면 한지 위에 붓글씨로 쓴 문장 카드가 만들어져요. 그때의 계절 수묵화가 배경에 깔리고, 위에는 문장갈피 제목, 아래에는 출처와 붉은 낙관이 들어가요.

  • 휴대폰에서는 공유 창이 바로 떠요. 카카오톡, 인스타그램 등으로 보내면 돼요.
  • 공유 창이 안 뜨는 환경에서는 이미지 파일로 저장돼요.

7백업과 옮기기

문장은 이 기기의 브라우저 안에만 저장돼요. 브라우저 데이터를 지우거나 앱을 지우면 함께 사라지니, 꼭 백업해 두세요. 오른쪽 위 ⚙️에서 해요.

방법 A. 파일로 백업

  1. ⚙️ → JSON으로 내보내기로 파일을 저장해요.
  2. 새 기기나 새로 설치한 앱에서 ⚙️ → JSON 파일 가져오기를 눌러 그 파일을 골라요.

방법 B. 백업 암호로 자동 백업

  1. ⚙️에서 백업 이름과 숫자 4자리 암호(선택으로 힌트)를 정하면, 문장을 담을 때마다 자동으로 백업돼요.
  2. 새 기기에서는 ⚙️ → 다른 기기의 백업에서 복구하기에 같은 암호를 넣으면 돌아와요.
암호는 다른 사람과 겹치지 않게 정하세요. 같은 4자리 암호를 쓰는 사람이 있으면 서로의 백업이 덮어씌워질 수 있어요. 암호와 백업 이름은 꼭 기억해 두고, 중요한 문장은 방법 A로도 한 번씩 저장해 두세요.

8그 밖의 기능

  • 📄 PDF 모음집 — ⚙️ 안의 PDF로 모음집 만들기를 누르면 모은 문장이 작은 책처럼 정리돼요. 인쇄 화면에서 PDF로 저장을 고르세요.
  • 🔗 공유하기 — 오른쪽 위 🔗에서 앱 주소의 QR코드와 링크 복사를 해요. 받은 사람은 자기만의 문장갈피를 따로 쓰게 돼요(문장이 섞이지 않아요).
  • 다른 곳에서 문장 바로 담기 — 안드로이드에서 앱을 홈 화면에 설치했다면, 다른 앱에서 글자를 선택하고 공유 → 문장갈피를 고르면 문장이 채워진 채로 열려요.

9자주 묻는 질문

문장이 모두 사라졌어요.

브라우저 데이터를 지웠거나 앱을 지웠다 다시 설치하면 사라져요. 백업해 둔 JSON 파일을 가져오거나, 백업 암호로 복구해 보세요.

휴대폰과 PC에서 같은 문장을 보고 싶어요.

자동 동기화는 없어요. 한쪽에서 JSON으로 내보내 다른 쪽에서 가져오거나, 백업 암호로 복구하세요.

배경이나 화면이 새 모습으로 안 바뀌어요.

앱을 새로고침하세요. 그래도 그대로면 앱을 완전히 닫았다가 다시 열어 주세요.

수정 창이 잘못 열렸어요.

아래쪽 취소, 위쪽 ✕, 창 바깥의 어두운 곳을 누르기 중 편한 것으로 닫으면 문장은 그대로예요.

효과가 너무 많거나 불편해요.

기기의 동작 줄이기 설정을 켜면 먹 번짐, 계절 낙하 효과가 꺼져요.

회원가입이나 요금이 있나요?

없어요. 로그인 없이 무료로 쓰고, 내 문장은 내 기기에만 저장돼요.
