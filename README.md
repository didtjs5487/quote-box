# quote-box (문장갈피)

명언, 명대사, 건배사, 개그, 성경 말씀 등 마음에 남는 문장을 태그로 자유롭게 분류해 모아두고 언제든 꺼내볼 수 있는 개인용 웹 앱입니다.
로그인이나 서버 없이, 브라우저의 로컬 저장소(localStorage)에만 데이터가 저장돼요.

## 사용법

그냥 `index.html`을 정적 호스팅(Netlify, Vercel, GitHub Pages 등)에 올리거나, 로컬에서 열면 됩니다.

```
npx serve .
```

- **오늘의 한마디**: 모아둔 문장 중 하나를 랜덤으로 보여줘요. 🎲를 누르면 다른 문장으로 바뀌어요. 아무리 길어도 전체가 그대로 보여요.
- **담아두기**: 문장, 출처(선택), 링크(선택 — 영상·기사 등 원본 주소)를 적어서 저장해요. 링크를 넣으면 카드에 "🔗 링크 보기"로 나오고, 누르면 새 탭에서 열려요.
- **느낀 점 · 깨달음 기록**: 문장을 누르면 그 자리에서 느낀 점을 남길 수 있어요. 댓글처럼 계속 이어서 여러 개 남길 수 있고, 각 기록마다 날짜(년.월.일)가 표시돼요. 기록을 누르면 수정, ✕를 누르면 삭제할 수 있어요. 검색에도 포함돼요.
- **태그로 분류**: 미리 정해진 카테고리 없이, 담아둘 때 "명언, 위로"처럼 쉼표로 원하는 태그를 자유롭게 붙이면 돼요. 등록된 태그는 자동으로 필터 칩(#명언, #위로…)이 되어 가나다순으로 나타나요. 칩을 누르거나 카드의 태그를 눌러 같은 주제끼리 모아볼 수 있어요.
- **검색 · 필터**: 검색창(태그도 검색돼요)과 필터 칩으로 원하는 문장을 빠르게 찾아요.
- **즐겨찾기**: 카드의 ☆을 눌러 즐겨찾기하면 "⭐ 즐겨찾기" 필터로 다시 볼 수 있어요.
- **수정 · 삭제**: 카드를 누르면 수정/삭제할 수 있어요.
- **내보내기 / 가져오기**: 오른쪽 위 ⚙️ 버튼에서 데이터를 JSON 파일로 내보내거나, 다른 기기/브라우저에서 가져올 수 있어요. (다른 기기와 자동으로 동기화되진 않아요 — 이 앱은 브라우저 로컬 저장만 사용해요.)
- **앱으로 설치(PWA)**: 배포된 주소를 크롬/사파리로 열면 "홈 화면에 추가" 또는 주소창의 설치 아이콘으로 앱처럼 설치할 수 있어요. 오프라인에서도 마지막으로 불러온 화면은 열려요.
- **공유하기**: 오른쪽 위 🔗 버튼을 누르면 앱 주소의 QR코드와 링크 복사 버튼이 나와요. 다른 사람에게 보내면, 그 사람은 자기 기기에 자신만의 문장갈피를 따로 만들어 쓸 수 있어요 (데이터는 서로 섞이지 않아요). 평소엔 접혀 있다가 🔗를 누를 때만 펼쳐져요.
- **다른 사이트에서 바로 담기**: ⚙️ 설정 안 "📌 문장갈피에 담기" 버튼을 북마크바로 드래그해두면, 다른 페이지에서 문장을 드래그해 선택한 뒤 눌러서 문장·출처·링크가 채워진 채로 담기 화면을 바로 열 수 있어요. 안드로이드에서 앱을 홈 화면에 설치했다면, 텍스트를 선택하고 "공유하기" → "문장갈피"를 골라도 똑같이 바로 담겨요.
- **백업 암호로 자동 백업 (선택)**: ⚙️ 설정에서 숫자 4자리 암호(+ 이름, + 힌트)를 정하면, 그때부터 문장을 담을 때마다 조용히 클라우드에도 자동 백업돼요. 로그인 화면은 없어요 — 암호는 처음 설정할 때, 그리고 나중에 다른 기기에서 복구할 때만 딱 한 번씩 입력하면 돼요. 이 기능을 쓰려면 아래 "백업 기능 설정(개발자용)"을 먼저 해야 해요.

## 백업 기능 설정 (개발자용)

"백업 암호로 자동 백업"은 파이어베이스(Firestore)가 있어야 동작해요. 설정 안 해도 앱의 나머지 기능은 전부 정상적으로 동작하고, 설정 화면에 "아직 백업 기능이 설정되지 않았어요"라고만 나와요.

1. https://console.firebase.google.com 에서 새 프로젝트를 만드세요.
2. 빌드 → Firestore Database → 데이터베이스 만들기 (테스트 모드로 시작해도 됩니다).
3. 프로젝트 설정(톱니바퀴) → 일반 → 내 앱 → "</>" (웹 앱)을 추가하세요.
4. `firebase-config.js`의 `firebaseConfig` 값을 발급받은 값으로 교체하세요.
5. `firestore.rules` 내용을 Firestore Database → 규칙 탭에 붙여넣고 게시하세요.

**참고**: 이 앱엔 로그인이 없어서, `backups`/`backupHints` 컬렉션은 접근 제어를 "암호를 아는 사람만 그 암호에 해당하는 문서에 접근 가능"한 정도로만 열어둬요(코드상 편의를 위한 최소한의 보안). 상업 서비스가 아니라 지인들끼리 개인용으로 쓰는 용도에 맞춘 설계예요.

## 참고 / 한계

- 백업 암호를 설정하지 않으면 데이터는 이 브라우저에만 저장돼요. 브라우저 저장공간을 지우면 데이터도 함께 사라지니, 백업 암호를 설정해두거나 가끔 내보내기로 백업해두는 걸 추천해요.
- 백업 암호를 설정해도, 브라우저 데이터를 완전히 초기화하거나 새 기기로 바꾸면 그 암호를 다시 입력해야 데이터가 돌아와요 (자동으로 이어지진 않아요).
- 여러 기기·여러 사람과 **같은 데이터를 실시간으로 공유**하려면 좀 더 큰 개편이 필요해요. 지금의 "공유하기"는 앱 자체를 퍼뜨리는 기능이고, "백업 암호"는 한 사람의 데이터를 여러 기기에 이어주는 기능이에요 — 둘 다 각자의 데이터가 서로 섞이지는 않아요.
